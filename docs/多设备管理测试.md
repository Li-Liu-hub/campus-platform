当前配置 `max-login-count: 3` 和 `overflow-logout-mode: REPLACED` 已体现出预期行为：第四次登录后只保留最近三台设备，最早的 `test-device-001` 被从 `terminalList` 淘汰，其 Token 映射被标记为 `-4`。
